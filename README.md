# Graph Traversal & Web Scraping Framework

## Overview
A Python-based framework for traversing graphs represented as matrices, files, and dynamically loaded web pages.
Supports DFS and BFS traversal using an extensible object-oriented design.

## Features
- Abstract GraphSearcher base class with DFS and BFS traversal
- Matrix, file-based, and web-based graph traversal
- Selenium-powered web crawler for dynamic content
- Aggregation of scraped table data into Pandas DataFrames
- Automated extraction of protected content

## Tech Stack
- Python
- Selenium
- Pandas
- Object-Oriented Programming (OOP)
